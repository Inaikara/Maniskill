# Triage labels

| Canonical role | 本地 Status 值 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待分类与核验 |
| needs-info | needs-info | 等待补充信息或用户决策 |
| ready-for-agent | ready-for-agent | 规格清楚，可由 agent 执行；仍须检查依赖 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |

这些标签描述 triage 角色；执行完成另以验收清单、证据及 `Completion` 记录。标签本身不代表实验达标。
